# أيهم — مشروع معرفي رقمي قيد التطوير (AYHEM)

![AYHEM Logo](assets/logo.png)

## الرؤية

AYHEM مشروع بحث وتطوير لبناء نظام معرفي رقمي يحفظ المعلومات بمصادرها، يربط التجارب عبر الزمن، ويتيح الاسترجاع والتحليل والاستدلال بصورة قابلة للتدقيق.

**الهدف طويل المدى** هو تطوير ذاكرة موثوقة، وتحليل قابل للقياس، واستقلالية منضبطة. هذه أهداف تطويرية وليست ادعاءً بأن النظام يمتلك وعياً بشرياً أو تعلماً ذاتياً مكتملاً أو تخزيناً غير قابل للمحو.

## البنية الأساسية

| الطبقة | المسؤولية |
|---|---|
| CORE | المبادئ والعقود وقواعد التشغيل |
| MEMORY | السجلات والمصادر والاسترجاع والتصحيحات |
| SYMBOLIC TEMPLATES | تنظيم التجارب في وحدات قابلة للفهرسة |
| ARCHIVE | التسلسل الزمني وحفظ النسخ |
| SIG | هوية المشروع وعلاماته المعرفية |

التفاصيل المرجعية في [وثيقة العمارة الأصلية](./ARCHITECTURE.md). كما توجد مواصفات أحدث قيد المراجعة في طلبات السحب، ولا تُعد المواصفات وحدها دليلاً على اكتمال التنفيذ.

## تقدم المشروع

لوحة التقدم المعتمدة موجودة في مستودع AYHEM_WEB:

[فتح لوحة التقدم الهندسي](https://github.com/samiaymen107-rgb/AYHEM_WEB/blob/main/AYHEM_PROGRESS_DASHBOARD.html)

تُحسب النسبة من ثمانية مجالات موزونة وبناءً على أدلة التنفيذ والاختبارات. وهي تقدير للنضج الهندسي، وليست نسبة جاهزية إنتاجية. لا يُعد وجود ملفات أو مخططات دليلاً كافياً على تشغيل وظيفة ما.

## حالة التطوير

- الذاكرة: توجد نواة تراكمية append-only فوق IndexedDB وصندوق مزامنة محلي دائم، وعميل push عبر HTTPS بموافقة صريحة مع SHA-256 والتحقق من الإقرارات. العميل غير مربوط بخادم منشور ولا يعمل تلقائياً؛ لا توجد مزامنة سحابية أو نقل بين الأجهزة أو استعادة بعيدة، ولم يُنفذ ترحيل بيانات المستخدم.
- الإدراك: توجد تحليلات أولية محافظة؛ الاستدلال الدلالي المعاير ما زال قيد التطوير.
- الاستقلالية: توجد أساسات سياسات ومهام محدودة، لكن التشغيل الذاتي المستمر لم يُثبت.
- الربط: يوجد عقد AI V1 قيد المراجعة؛ لا يُدّعى أن بوابة AI حية حتى ينجح اختبار فعلي على الخدمة المنشورة.
- الأمان: لا تحفظ مفاتيح المزود أو رموز الوصول في المستودع أو الواجهة.

## مبادئ السلامة

1. لا تُحوّل الفرضيات أو الاستنتاجات إلى حقائق.
2. لا تُعدّل السجل الأصلي بصمت؛ اربط التصحيح بالمصدر.
3. لا تُنفذ ترحيلاً أو حذفاً نهائياً لبيانات المستخدم دون موافقة وخطة استعادة مختبرة.
4. لا تمنح أي وحدة نفسها صلاحيات جديدة.
5. لا تضع الأسرار في Git أو كود المتصفح.
6. لا تعلن عن ميزة أو خدمة باعتبارها حية إلا بعد اختبارها في بيئتها الفعلية.
